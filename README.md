# TIC TAC TOE GAME

**ABOUT THE PROJECT**

The Tic Tac Toe Game is a console-based application developed using C programming. It allows two players to play on a 3×3 board. Player 1 uses X, and Player 2 uses O. The game checks winning conditions and declares the winner or a draw.

**FEATURES**

- Two-Player Gameplay.
- 3×3 Game Board.
- Move Validation.
- Winner Detection.
- Horizontal, Vertical and Diagonal Checking.
- Draw Detection.
- Replay Option.

**GAME RULES**

- Player 1 uses X.
- Player 2 uses O.
- Players take turns selecting positions from 1 to 9.
- Already occupied positions cannot be selected.
- The first player to get three matching symbols in a row, column, or diagonal wins.
- If all positions are filled without a winner, the game ends in a draw.

**TECHNOLOGIES USED**

- Programming Language: C
- Compiler: GCC
- Concepts: Structures, Pointers, 2D Arrays, Functions, Loops and Conditional Statements.
